# docs/ — 设计文档与实施计划

职责：沉淀各轮迭代（rev*）的设计案、取舍记录、实测数据与分阶段实施计划，供实现与复审引用。

## 目录结构

| 路径 | 作用 |
|---|---|
| `superpowers/specs/` | 各轮设计案（需求拆解、方案、验收标准、风险） |
| `superpowers/plans/` | 分阶段实施计划（任务拆分与涉及文件） |

## 约定

- 文件名形如 `YYYY-MM-DD-<主题>-design.md` / `-<阶段>-plan.md`。
- 每份设计案包含：需求拆解表、方案设计、实施计划、验收标准、风险与边界。
- 实测记录（真机隔离验证的原始数据）直接写入对应设计案，作为历史留存。

## 修改注意点

- 设计案是对应版本的历史记录，除修订实测记录外不要回改成"当前状态"口径。
- 新增 rev 时同时补设计案与计划，并在 README 的「项目结构/功能」中反映。
