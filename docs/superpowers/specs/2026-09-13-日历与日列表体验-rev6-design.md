# 作业日程 — 日历与日列表体验设计（rev6）

> 需求已与用户确认：① 日列表按条数**动态高度**（1 条→1 条位、2 条→2 条位…），每页最多 3 条，超出用**圆点页码 + 箭头**翻页；② 日期格改**近似圆角正方形**，修复小档位数字与圆点重叠；圆点是否缩放按视觉实际效果定；③ 腾出的空间——**窗口高度随内容自适应**（切换日期时窗口变高/变矮，可平滑动画），窗口内不留空白；④ 实现后**用视觉模型检查美术效果**并按结论调整。

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-13 |
| 分支 | `feature/cal-rev6`（基于 master @ `b105808`） |
| 基线 | rev5 完成（实时缩放/锚定/最小字号+紧凑滚动）；后端 120 / 前端 21 全绿 |
| 量测（现状，408×760） | 日期格 53.7×48.5px（扁 ~10%）；compact 28.7×26px **数字与圆点重叠**；日面板固定占 **322px**（1 条日程时约 240px 为空） |

## 1. 需求拆解

| # | 要求 | 目标定义 |
|---|---|---|
| R1 | 日列表动态高度 | 面板高度=内容高度：0 条→空提示行；1/2/3 条→1/2/3 行；窗口**不留空白** |
| R2 | 分页 | 每页最多 3 条；>3 条时出现「◀ ● ○ ▶」：圆点数=页数（当前页高亮）、箭头翻页、首/末页箭头禁用、切日期复位第 1 页 |
| R3 | 日期格形状 | 每格**近似圆角正方形**（1:1±2%）；数字与圆点**任何档位不重叠**；圆点尺寸随格宽缩放（clamp） |
| R4 | 空间处理（已确认） | **窗口高度自适应内容**：H = 内容高(CSS)×zoom，切换日期/翻页时窗口平滑变高矮 |
| R5 | 美术验收 | 视觉模型对 40/70/100/150% 档位按用户视角评审（格形/圆点/分页/整体），按结论调整后复评 |

## 2. 现状与约束

- 窗口尺寸 = 408×760 × scale（rev5），布局按 100vh 固定高度铺满 → 日列表 `flex:1` 吃掉所有剩余空间（322px 固定）。
- 日期格 `grid-auto-rows:minmax(0,1fr)`（被拉伸成扁矩形）；数字为 `btn.textContent` 居中，圆点 `position:absolute; bottom:4px` → 小格必重叠。
- rev5 的 `body.compact`（<70%）机制：字号下限 + 视口收窄 + **纵向滚动**——本设计以「自适应高度」取代其滚动职责（仅当工作区放不下时保留滚动兜底）。
- 关键约束：`window_scale` 决定宽度 `W=408×s` 与 zoom `z=max(s,0.7)`；窗口位置记忆/贴边/钳制体系不变。

## 3. 方案设计

### 3.1 窗口高度自适应（R1/R4）

- **CSS 改为自然高度**：`.widget { height: auto }`（去除 100vh）；`.calendar { flex: none; grid-auto-rows: auto }`；`.day-panel/.day-list { flex: none }`——全页无 100vh 依赖（内容高 `Hc` 与视口高解耦，消除反馈环）。
- **渲染层上报**：新增 IPC `shell:fit-height(Hc)`；`reportFit()` 在 `init/renderMonth/renderDay/window resize`（rAF 去抖 + 值去重）后测量 `#app.offsetHeight`（CSS px）上报。
- **主进程**：目标高度 `H = round(Hc × z)`；与现有平滑循环合并——每帧同步逼近 `(scale, H)`，两侧收敛（|Δ|<0.5）后停；应用 `setContentSize(W,H)` + `setZoomFactor(z)`，随后按工作区钳制位置（向下生长；底越界则上移）。
- **启动体验**：窗口先 `show:false`，**首个 fit-height 上报后再 show**（1.2s 超时兜底），避免"先大后缩"的闪烁。
- **工作区兜底**：若 `H` 被工作区钳制（小屏/大档位），内容溢出 → 由 3.4 的溢出滚动接管。
- 读数：`p%（W×H）` 取当前实际值（缩放 IPC 返回值 / `getWindowInfo`）。

### 3.2 日列表动态高度 + 分页（R1/R2）

- 面板高度天然=内容高度（3.1 已保证）；行高沿用现制（li padding 6/8 + 单行 33px）。
- `PAGE_SIZE=3`；`state.dayPage`（`loadDay/selectDate` 复位 0）；`renderDay` 渲染 `rows.slice(page*3, page*3+3)`。
- 分页器（`index.html` 新增于 `.day-panel` 内、`#day-list` 之后）：
```html
<div id="day-pager" class="day-pager" hidden>
  <button id="pager-prev" class="icon-btn small" title="上一页">◀</button>
  <span id="pager-dots" class="pager-dots"></span>
  <button id="pager-next" class="icon-btn small" title="下一页">▶</button>
</div>
```
- 圆点：每页一个 `.pager-dot`（当前页 `.active`），点击跳页；箭头首/末页 `disabled`。仅总页数>1 时显示。
- 0 条：维持「这一天还没有安排」空提示（自然高度）。

### 3.3 日期格：圆角正方形 + 数字/圆点布局（R3）

- `.cell { aspect-ratio: 1; border-radius: 12px; }`（行高由格宽决定；7 列 1fr）。
- **布局消除重叠**（任意尺寸成立）：每格固定两行结构——数字居中于第 1 行、圆点区固定在第 2 行（`display:grid; grid-template-rows: 1fr auto`；圆点区每格常驻，含 0 个圆点也占位 → 全网格基线一致、不再绝对定位）：
  - 数字改 `<span class="num">`（不再用 `textContent`）；
  - 圆点区 `.dots`（既定样式保留 sched/bb 两色与选中反白）。
- **圆点随格缩放**（`container-type: inline-size` 于 `.calendar`）：
  - `.cell .dot { width: clamp(3px, 1.25cqw, 5px); height: same; }`（408 视口≈5px，233 视口≈3px）；
  - 数字字号轻微自适应：`.cell { font-size: clamp(12px, 3.4cqw, 14px) }`（40% 档 12px、100% 档 14px），保证小格不挤——**由视觉走查定档**。
- `.cell.out/.today/.selected` 样式沿用（选中反白圆点已有）。

### 3.4 溢出滚动兜底（取代 rev5 compact 滚动）

- `body.compact` 系列规则**移除**（其触发条件与职责被 3.1 取代）；设置弹层的 compact 补丁同去（widget==视口，包含块问题消失）。
- 新增 `body.overflowing`（由 `reportFit()` 检测 `documentElement.scrollHeight > clientHeight+1` 切换）：
  `html:has(body.overflowing), body.overflowing { overflow-y:auto; scrollbar-width:auto }` + 既有 6px 细滚动条规则（选择器替换）。
- 仅当工作区钳制导致内容放不下时出现滚动条；正常情况窗口完整展示全部内容。

### 3.5 交互与兼容

- `window_scale` 语义保持（宽度 + zoom 下限）；高度不再由 scale 直接决定，而是 `Hc×z`。
- 贴边收起/唤出、位置记忆、缩放平滑、锚定、透明度等机制不变；收起前先收敛（既有逻辑）。
- 切日期/翻页 → 上报 fit → 窗口平滑变高矮（复用 rev5 平滑循环）。

## 5. 验收标准

1. 回归：backend 120 / frontend 21 全绿；`node --check` 通过。
2. **R1/R4**：窗口内无空白——`#app.offsetHeight ≈ innerHeight`（±1）；1/2/3 条日程时窗口高度分别为对应内容高；切换日期窗口平滑变高矮；`init` 后无"先大后缩"闪烁（首帧即目标尺寸 ±2px）。
3. **R2**：>3 条出现分页器；圆点数=页数、当前页高亮；箭头翻页正确、首/末页禁用；切日期复位第 1 页；第 2 页内容正确。
4. **R3**：日期格宽高比 1±2%、圆角；**任意档位数字与圆点无重叠**（几何断言：数字底 ≤ 圆点顶，含 40% 档）；圆点尺寸随格宽缩放（40%≈3px、100%≈5px）。
5. 溢出兜底：工作区钳制场景出现细滚动条且滚轮可用；正常场景无滚动条。
6. 隔离测试、进程/端口零残留、无凭据落盘。
7. **R5**：视觉模型对四档位美术评审通过（调整项落地并复评）。

## 6. 风险与边界

- 自适应高度使窗口在切日期时变高矮：用平滑动画缓解；极端数据（一天几十条）由分页封顶为 3 行+分页器。
- 低档位（40%）下视口约 233px 宽：格约 28.7px 方形、数字 12px——是否可读以视觉走查为准（必要时微调 clamp 下限）。
- 移除 `body.compact` 属对 rev5 表现的取代性变更（滚动仅在钳制场景保留），rev5 文档作为历史保留。
- 每格常驻圆点占位行会略抬高数字视觉位置（全网格一致），观感由走查确认。

## 7. 实测记录（T1/T2 真机与视觉走查）

### 7.1 交互与机制（隔离真机）

- **高度自适应**：15 组（100/70/40/150/85% × 1/3/6 条）`app≈inner ±2`；100% 下 0/1/2/3/6 条 = 550/553/586/619/645；切日期 11 个过渡帧。
- **分页**：>3 显示「◀ ● ● ▶」；圆点数=页数、当前页高亮、端点禁用、翻页/点跳/切日期复位全部正确。
- **方形格**：宽高比 1.000（100% 与 40%）、数字-圆点零重叠、圆点 5.23→3.50px 随格缩放。
- **溢出稳定**：70/83/85% 静置 8s 翻转 0（滞回 8/1）；合成夹制场景 1 进 1 出、无抖动。
- **冷启动**：可见首帧 = 终值（±0/±1）、导航→可见 404ms（修复前约 2.2s）。
- **回归**：缩放拖动/锚定（漂移 ≤0.9px）/透明度/持久化（写 40 重启生效）/收起唤出均正常。

### 7.2 视觉模型美术走查（16 张 + 复评 5 张）

- 初审问题（原样摘录）：格子间距偏紧；圆点「太小、太靠下」；选中日白点「对比度稍低」；分页「箭头太小、颜色灰暗」「圆点太小（约 3px）」。
- 调整（`52efda2`，仅 `style.css`）：`.calendar` gap 2→3px；`.dot` → `clamp(3.5px,1.35cqw,5.5px)` + gap 4 + margin 3；选中白点加对比描边；`.pager-dot` 6→8px（对比度提高、当前页描边环）；分页箭头加深加大。
- 复评：40/70/100% 关键图 **8.5/10**、「非常像（成熟产品）」「分页圆点+箭头清楚好看、简洁明了」。
