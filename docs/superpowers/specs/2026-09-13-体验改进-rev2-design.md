## 2. 开发与测试期间发现的问题（整合清单）

### 2.1 真实账号探测（今日执行，只读）

- 账号可正常登录；`uid` 已脱敏（形如 `_6xxxx_1`）；**31 门课程**（含历史学期 Spring 2026）；**240 条作业记录**，其中仅部分有 `due`（截止时间来自评分列）。
- 发现：存在 **`due=null` 的作业**（如某课程"第一周作业"）——当前设计不进入日历/列表，**完全不可见**；且部分历史作业截止时间在 2025 年（课程模板遗留），浏览历史月份会看到旧数据。
- 发现：`uploadAssignment?action=newAttempt` 链接对**无提交入口**的项会落到"项目不可用"页（不是稳定入口）。
- 结论：**BB 外链主格式改用 `listContent.jsp`（内容页，实测标题正确）+ `courseMain`（课程首页，作回退）**（见 §4.5）。

### 2.2 开发环境经验（避免后续踩坑）

| 事项 | 现象 | 对策 |
|---|---|---|
| 中文路径 + PS 5.1 | 无 BOM 的中文 `.ps1` 被按 ANSI 误读 | 脚本存 **UTF-8 BOM** |
| `npx` | Windows 上直接调 `npx` 报 "不是有效的 Win32 程序" | 统一 `npx.cmd` |

| 长驻子进程 | 工具封装会终止持有管道的外层 shell | 后台进程 + 输出落盘轮询（dev 启动后端等场景） |

## 3. 根因分析（针对 R1 两项）

- **渐变黑边** = ① `.widget` 的 `box-shadow`（窗口透明时投影直接渲染在桌面上呈深色渐变晕）＋ ② Electron 无边框窗口的 **OS 阴影**（Win11 DWM 默认给窗口加阴影，`hasShadow` 未关）＋ ③ `body` 外边距让窗口四周留出透明空区，放大晕感。
- **滚动条** = 内容总高（登录卡 + 日历 + 日面板）可能超过窗口 760px，`html/body` 未禁滚动 → 窗口右缘出现页面级滚动条。

## 4. 方案设计

### 4.1 R1 窗口外观（涉及 `frontend/style.css`、`electron/main.js`）

- `main.js`：`BrowserWindow` 增加 **`hasShadow: false`**。
- `style.css`：
  ```css
  html, body { height: 100%; margin: 0; overflow: hidden; background: transparent; }
  * { scrollbar-width: none; }            /* Firefox/标准 */
  *::-webkit-scrollbar { display: none; } /* Chromium */
  .widget {
    width: 100%; height: 100vh; margin: 0;
    border-radius: 16px; box-shadow: none; border: none;
    display: flex; flex-direction: column;
  }
  .day-panel { flex: 1; min-height: 0; display: flex; flex-direction: column; }
  .day-list  { flex: 1; overflow-y: auto; }   /* 仅在内部滚动，且无可见滚动条 */
  ```
- 窗口尺寸维持 408×760（`useContentSize`）；圆角外的区域保持透明露出桌面。

### 4.2 R2 状态栏常驻 + 手动拉取按钮（`index.html`/`app.js`/`style.css`）

- 状态栏**始终显示**：左侧状态文案（无内容时显示「尚未同步」），右侧 `<button id="btn-status-sync">⟳</button>`。
- 点击走既有 `doSync()`（同步中禁用 + 「同步中…」；含 busy/离线处理）。

### 4.3 R3 BB 提醒时间选择器（`index.html`/`app.js`）

- 两个提醒槽（可理解为"第一/第二提醒"），每槽：**天（0–30）+ 小时（0–23）** 两个 `select`（`2855c12` 起天数范围 0–30，兼容越界历史值回填；原设计 0–7）。
- 取值 = `天×24 + 小时`（小时），**转换为分钟**存入既有 `bb_remind_defaults`（后端单位分钟，未改协议）。
- 默认：提醒1 = 1 天 0 小时；提醒2 = 0 天 2 小时（等价现有 `[1440, 120]`）。
- 校验：两槽不得同时为 0 天 0 小时；重复值自动去重。

### 4.4 R4 设置面板分组与条件展开（`index.html`/`app.js`/`style.css`）

结构（大标题 + 子项）：

```
设置
├─ BB 日程设置
│   ├─ 同步间隔（分钟）
│   └─ [√] BB 作业截止提醒
│         └─ （勾选后展开）默认提醒时间：提醒1 天/小时；提醒2 天/小时
├─ 提醒
│   └─ 提醒形式（气泡 / 系统通知 / 两者）
├─ 窗口
│   ├─ 窗口置顶 [√]
│   ├─ 透明度（0.3–1.0）
│   └─ 开机自启 [√]
└─ 账号
    └─ 退出登录
```

- 样式：`.settings-group h4`（大标题，加分隔线），子项缩进。
- 条件展开：`#s-bb-remind` 的 `change` 与打开面板时同步 `#bb-remind-detail` 的 `hidden`。

### 4.5 R5 事务信息概览 + BB 外链（`index.html`/`app.js`/`preload.js`/`main.js`）

- 新增 `#modal-item` 概览弹层，点击**任意**事务行打开：
  - 通用：标题、备注（无则「—」）、开始/结束时间、提醒（如「提前 1 天 2 小时」/「不提醒」）、来源（自建/BB）
  - BB 追加：课程名、截止时间、提交状态（已提交/未提交 + 评分状态）、分数（有则显示）
  - 按钮：自建 →「编辑」（转既有编辑弹层）；BB →「在 Blackboard 中打开」；均可「关闭」
- **BB 外链格式（真实账号已验证）**：
  - 主：`https://bb.sustech.edu.cn/webapps/blackboard/content/listContent.jsp?course_id=_{course_id}_1&content_id=_{content_id}_1`（实测直达内容页，标题含作业名与课程名）
  - 回退（无 content_id）：`https://bb.sustech.edu.cn/webapps/blackboard/execute/courseMain?course_id=_{course_id}_1`
- 打开方式：Electron 经新增 `hwShell.openExternal(url)`（主进程 `shell.openExternal` + IPC `shell:open-external`）；浏览器环境 `window.open(url, "_blank", "noopener")`。
- 提前时间的可读化：新增纯函数 `formatLead(seconds)` → 「1 天 2 小时」/「30 分钟」（进 `lib/fmt.js` + node 测试）。

### 4.6 R6 BB 标题带课程名（`app.js`）

- 日列表中 BB 行标题：`course_name` 存在时渲染为 **`【课程名】标题`**；概览弹层中课程名单列一行。
